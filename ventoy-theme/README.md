# Тема Ventoy «DNS»

Загрузочное меню Ventoy в стиле DNS: оранжевая шапка с заголовком «DNS» и подписью
«Windows 11 Домашняя / Pro · инструменты · восстановление», тёмный фон, меню в
тёмной панели, синяя подсветка выбранного пункта.

Проверено на Ventoy **1.1.18** (UEFI, QEMU/OVMF) — скриншот `preview.png`.

## Как сделать флешку с этой картинкой

1. Как обычно установите Ventoy на флешку через `Ventoy2Disk.exe` (версия 1.1.18).
2. Скопируйте папку [`ventoy/`](ventoy) из этого каталога в **корень** флешки
   (раздел с меткой `Ventoy`, куда кладутся ISO). Должно получиться:

   ```
   E:\ventoy\ventoy.json
   E:\ventoy\theme\theme.txt
   E:\ventoy\theme\background.png
   E:\ventoy\theme\*.png
   E:\Windows11.iso ...
   ```

   Или запустите `install_theme.cmd` (сам найдёт флешку по метке `Ventoy`,
   либо укажите букву: `install_theme.cmd E:`). Если на флешке уже был
   `ventoy.json`, он сохранится как `ventoy.json.bak`.
3. Кладите ISO на флешку как обычно — при загрузке будет меню с картинкой DNS.

Переустановка/обновление Ventoy через `Ventoy2Disk.exe` (кнопка «Обновить») раздел
с ISO не трогает, тема остаётся. Для новых флешек повторите шаг 2.

## Если на флешке уже есть свой `ventoy.json`

Не затирайте его — перенесите в него только блок `"theme"` из
[`ventoy/ventoy.json`](ventoy/ventoy.json) (остальные плагины — `menu_alias`,
`auto_install` и т.д. — можно оставить).

## Поменять текст на картинке

Заголовок и подпись нарисованы прямо в `background.png`. Чтобы поменять их,
перегенерируйте тему (нужен Python 3 и `pip install pillow`):

```bash
python build_theme.py --title "DNS" --subtitle "Windows 10/11 · Live-CD · диагностика"
```

Скрипт перезапишет папку `ventoy/`. Шрифт — Liberation Sans / Arial
(ищется в системе автоматически).

## Что где настроено

| Элемент | Где |
|---|---|
| Шапка, линия, тёмная панель меню | `background.png` (генерирует `build_theme.py`) |
| Положение меню, цвета пунктов, подсветка, таймер, строка клавиш | `theme/theme.txt` |
| Разрешение 1024×768, цвет строки версии Ventoy | `ventoy.json` → `theme` |

Разрешение зафиксировано на 1024×768 (`gfxmode`), потому что позиция меню задана
в пикселях под панель на фоне.
