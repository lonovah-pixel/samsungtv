## 2. Что нужно от вас (только чтение, ничего не меняет)

1. **Меню → Поддержка → Об этом телевизоре**: полный «Код модели» (например `UE49NU7300UXRU`), «Версия ПО» (`T-KTM2…-xxxx.x`), «Серийный номер» (можно скрыть последние цифры). Фото экрана подойдёт.
2. **Наклейка на задней крышке**: Model code, Version (`TS01`, `FA01` и т. п.), дата производства.
3. **Если ТВ в одной сети с ПК/Linux-машиной**: `tools/tv_probe.sh <IP-телевизора>` — делает только HTTP GET к `http://IP:8001/api/v2/` (ТВ сам отдаёт модель, ОС, платформу) и проверяет открытые порты. Пришлите результат.
4. **Как сейчас выглядит проблема**: что именно тормозит (меню, запуск приложений, YouTube), и насколько важно сохранить эфирный тюнер, HDR и пульт.
5. **Happ**: правильно ли я понимаю, что это VPN/прокси-клиент Happ (Xray/V2Ray)? Какие ещё приложения в «и т. д.» — особенно стриминг (Netflix, YouTube, Кинопоиск, IVI и пр.), им нужен DRM.
6. **Бюджет и готовность к риску**: допустимо ли покупать внешнюю приставку и/или паяльные работы (UART) на телевизоре.

**В сервисное меню (Info→Menu→Mute→Power) без инструкции не заходите**: изменения там могут сломать панель/регион.

## 3. Порт Android TV / AOSP на саму плату: разбор по компонентам

Для работающей Android TV нужны: разблокируемый загрузчик (или обход подписи), ядро с исходниками и драйверами,
Android HAL-ы и закрытые userspace-библиотеки от производителя SoC. По Samsung TV SoC ситуация такая:

| Компонент | Что нужно для Android | Что доступно | Оценка |
|---|---|---|---|
| Загрузчик / secure boot | Возможность загрузить своё ядро/рамдиск | Подписанная цепочка, публичного обхода для N-серии нет; ROOT ≠ своё ядро | ❌ блокер |
| Исходники ядра | Ядро + device tree | Samsung публикует GPL-исходники на opensource.samsung.com, но без Android-патчей; проверить для T-KTM2 | ⚠️ частично |
| BSP / HAL | gralloc, hwcomposer, audio, codec2/OMX, tv_input, CEC | Не существует для этой платы | ❌ |
| Дисплей / панель (scaler, T-CON, local dimming, 4K вывод) | Драйвер вывода видео-плоскостей | Проприетарный стек Samsung | ❌ |
| GPU (Mali, предположительно) | Userspace-драйвер EGL/GLES для Android | Только kernel-часть GPL; Android-blob под этот SoC не публиковался | ❌ |
| Аппаратное декодирование HEVC/VP9 4K | Codec2/OMX-компонент | Проприетарный, только для Tizen | ❌ (без него 4K-видео не будет, программное декодирование не потянет) |
| Звук (динамики, ARC, оптика) | Audio HAL | Проприетарный | ❌ |
| Wi-Fi / Bluetooth | Драйвер модуля (обычно USB/SDIO, модель модуля ❓) | Возможно, mainline-драйвер есть — зависит от чипа | ⚠️ |
| Пульт (ИК, Bluetooth Smart Remote) | Input-драйвер | ИК — через микроконтроллер платы, протокол не задокументирован | ❌/⚠️ |
| HDMI-входы, CEC | tv_input HAL | Проприетарно | ❌ |
| ТВ-тюнер DVB-T2/C/S2, CI+ | TIF + драйвер демодулятора | Проприетарно | ❌ |
| DRM (Widevine) | Widevine L1 + сертификация Google | Невозможно для самодельной сборки | ❌ |

**Вывод по пункту 3:** даже в лучшем случае (найден root-эксплойт и обход проверки подписи)
вы получите Linux-ядро без драйверов вывода видео, GPU, декодера, звука и тюнера. Портов Android
на любые Samsung Tizen-ТВ, подтверждённых работой, я не нашёл ни в одном источнике
([пример обсуждения на SamyGO](https://forum.samygo.tv/viewtopic.php?p=112510) — ответы отрицательные).
Статьи «как поменять Tizen на Android» в выдаче — низкого качества и без доказательств.

## 4. Приложения, Google Play, DRM

- **Happ** — клиент для Android/Android TV (ставится из Google Play на Android TV, [инструкция BlancVPN](https://blancvpn.com/help/how-to-set-up-v2ray-happ-on-android-tv)). Под Tizen нативных VPN-клиентов нет: Tizen не даёт сторонним приложениям API для VPN ([Windscribe](https://windscribe.com/features/samsung-tv), [NordVPN](https://nordvpn.com/blog/vpn-on-samsung-tv/)).
- **Google Play / Google-сервисы** — только на сертифицированных Google устройствах. Самодельная сборка сертификацию не получит, Play Integrity не пройдёт.
- **DRM** — HD/4K в Netflix и аналогах требует Widevine L1 + сертификации. На самодельном AOSP будет максимум L3 (SD) или отказ воспроизведения.

## 5. Итог и сравнение вариантов

**Прямой порт Android TV на UE49NU7300U с доступными ресурсами нереализуем.** Отсутствуют: способ загрузить своё ядро
(подписанная загрузка), BSP/HAL, драйверы GPU, видео-декодера, дисплейного тракта, звука, HDMI/CEC и тюнера, а также DRM.
Объём работ — реверс-инжиниринг проприетарного SoC без документации, многолетний для команды, с высоким риском превратить ТВ в «кирпич».
Поэтому я не буду готовить «прошивку» — образ без этих драйверов был бы фиктивным.

| Вариант | Плавность UI | Happ / Android-приложения | 4K HDR / DRM | Риск | Цена |
|---|---|---|---|---|---|
| A. Порт Android на плату ТВ | — | — | — | Очень высокий (кирпич) | Не реализуемо |
| B. Оптимизация штатного Tizen | Небольшой прирост | Happ нет; VPN — только через роутер | Есть (штатные приложения) | Низкий | 0 |
| C. **Внешнее сертифицированное Google TV / Android TV устройство по HDMI** | Зависит от устройства, измеряется | Да, Google Play | Widevine L1 на сертифицированных моделях | Нулевой для ТВ | от ~$30–150 |
| D. VPN на роутере (дополнительно к B или C) | — | Не нужно приложение на ТВ | Не влияет | Низкий | Роутер с поддержкой Xray/WireGuard |

**Рекомендация:** вариант C. Плата ТВ не меняется; приставка подключается к HDMI-порту ТВ (4K60 HDR10, нужно
подтвердить в спецификации порта), а через HDMI-CEC (Anynet+) включение и громкость управляются одним пультом.
При выборе приставки проверить: сертификацию Google TV/Android TV, Widevine L1, поддержку 4K HDR10, объём RAM ≥ 2 ГБ,
наличие нужных приложений в региональном Play. Конкретные модели назову после ваших ответов о бюджете и сервисах.

### Что можно сделать со штатной системой (B), без риска
1. Обновить ПО через «Поддержка → Обновление ПО» (последние сборки T-KTM2 датированы 2022–2024).
2. Удалить неиспользуемые приложения, отключить автозапуск последнего приложения и «Автозапуск Smart Hub».
3. «Поддержка → Уход за устройством» (если есть в вашей версии) — очистка памяти.
4. Сброс Smart Hub; при сильных тормозах — сброс к заводским настройкам (стирает учётные записи).
5. Для отклика на видео — «Игровой режим» на нужном HDMI-входе.

## 6. План проверки перед выбором (метрики, не обещания)

Скорость «как у Tizen» не гарантируется ни одним вариантом без измерений. Предлагаемые метрики для сравнения ТВ и приставки:

| Метрика | Как мерить |
|---|---|
| Холодный старт до главного экрана | Секундомер / видео на телефон 60 fps, 5 прогонов, медиана |
| Отклик навигации | Видео 240 fps: нажатие кнопки → смена фокуса, мс |
| Запуск YouTube / Happ | Время до первого интерактивного экрана, 5 прогонов |
| Свободная RAM (Android) | `adb shell dumpsys meminfo`, `cat /proc/meminfo` |
| Видео | 4K60 HDR10 тестовый ролик: пропуски кадров (`dumpsys media.codec`, статистика для гиков YouTube) |
| Звук / ARC / CEC | Звук через динамики ТВ и саундбар; включение/громкость с пульта ТВ |
| Сеть | Скорость через Happ, Wi-Fi vs Ethernet |
